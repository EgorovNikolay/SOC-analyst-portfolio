# Спринт 5. Расследование целевой фишинговой атаки с компрометацией контроллера домена

## О проекте

В этом спринте расследовал целевую атаку на инфраструктуру Demo Lab, которая произошла 15 апреля 2025 года.

Атака началась с фишингового письма с вредоносным вложением `Financial_Report_Q1_2025.exe`. После запуска файла злоумышленник получил доступ к рабочей станции `ws7` с IP `10.0.0.27`, затем переместился на контроллер домена `dc01` и файловый сервер `fileserver`.

В ходе атаки были собраны конфиденциальные документы, создан архив `data.zip`, после чего данные были переданы на внешние серверы. В конце злоумышленник удалил часть артефактов и очистил журналы.

Основная задача была восстановить полную цепочку атаки, определить IoC, сопоставить действия с MITRE ATT&CK и подготовить детекты и материалы для реагирования.

## Что делал

- анализировал события в ELK
- восстанавливал хронологию атаки
- разбирал фишинговое письмо и запуск вложения
- анализировал создание и запуск подозрительных файлов
- проверял изменения в реестре
- отслеживал команды разведки
- разбирал RDP и SMB как этапы бокового перемещения
- анализировал доступ к конфиденциальным файлам
- отслеживал создание архива и передачу данных
- искал признаки очистки логов и удаления артефактов
- собирал IoC
- сопоставлял действия с MITRE ATT&CK
- исправлял и создавал правила корреляции
- готовил технический и управленческий отчёты
- разрабатывал плейбук реагирования

## Что удалось обнаружить

### Первоначальный доступ

Пользователь получил фишинговое письмо с вложением:

`Financial_Report_Q1_2025.exe`

В `08:28:51` файл был запущен на рабочей станции `ws7`.

### Закрепление

После запуска вложения были созданы компоненты DarkGate и внесены изменения в реестр.

В дальнейшем на хосте появлялись файлы:

- `Autoit3.exe`
- `msedge-update.exe`
- `cryptoservice.exe`

### Разведка

Около `10:03` злоумышленник запускал стандартные системные утилиты:

- `net`
- `ipconfig`
- `whoami`
- `tasklist`
- `netstat`

Эта активность использовалась для сбора информации о системе и окружении.

### Боковое перемещение

В `11:00:46` было зафиксировано RDP-подключение к контроллеру домена `dc01` под учётной записью `administrator`.

Позже был получен доступ к файловому серверу через административную шару `C$`.

### Доступ к данным

На файловом сервере были прочитаны конфиденциальные документы:

- `Q1_2025_Budget.xlsx`
- `Employee_Records_2025.xlsx`
- `Strategic_Plan_2025-2027.docx`
- `admin_credentials.xlsx`
- `Project_Quantum_Specs.pdf`

После этого был создан архив:

`data.zip`

### Эксфильтрация

Передача данных была зафиксирована в `16:07:10` и `16:16:32`.

Общий объём переданных данных составил около 39 МБ.

### Сокрытие следов

В конце атаки были обнаружены:

- удаление артефактов
- очистка журналов Windows
- использование `wevtutil.exe`

## Сопоставление с MITRE ATT&CK

По ходу расследования сопоставил основные действия злоумышленника с MITRE ATT&CK.

Основные техники:

- **T1566.001 Spearphishing Attachment**  
  Фишинговое письмо с вредоносным вложением `Financial_Report_Q1_2025.exe`

- **T1204.002 Malicious File**  
  Запуск вредоносного вложения пользователем

- **T1547.001 Registry Run Keys / Startup Folder**  
  Закрепление через запись в реестре для автозапуска AutoIt

- **T1071.001 Web Protocols**  
  C2-соединения по HTTPS

- **T1572 Protocol Tunneling**  
  Туннелирование трафика через `mscvs.exe`

- **T1087.001 Local Account Discovery**  
  Получение информации о локальных учётных записях через `net.exe`

- **T1087.002 Domain Account Discovery**  
  Сбор информации о доменных учётных записях через `csvde.exe` и `ldifde.exe`

- **T1016 System Network Configuration Discovery**  
  Получение сетевой конфигурации через `ipconfig /all`

- **T1033 System Owner/User Discovery**  
  Определение текущего пользователя через `whoami`

- **T1049 System Network Connections Discovery**  
  Просмотр сетевых соединений через `netstat -ano`

- **T1021.001 Remote Desktop Protocol**  
  RDP-подключение с `ws7` на контроллер домена под учётной записью `administrator`

- **T1021.002 SMB/Windows Admin Shares**  
  Доступ к административной шаре `C$` на файловом сервере

- **T1105 Ingress Tool Transfer**  
  Передача `msedge-update.exe` и `cryptoservice.exe` на другие хосты

- **T1005 Data from Local System**  
  Чтение конфиденциальных файлов на файловом сервере

- **T1560.001 Archive Collected Data**  
  Создание архива `data.zip`

- **T1003.001 LSASS Memory**  
  Запуск `LaZagne.exe` и попытка доступа к памяти LSASS

- **T1069.002 Domain Groups Discovery**  
  Сбор информации о группах Active Directory через `csvde.exe` и `ldifde.exe`

- **T1048 Exfiltration Over Alternative Protocol**  
  Передача `data.zip` на внешний C2-сервер

- **T1070.004 File Deletion**  
  Удаление вредоносных файлов, архива и других артефактов атаки

- **T1070.001 Clear Windows Event Logs**  
  Очистка журналов Windows через `wevtutil.exe`

## Правила корреляции

В рамках спринта исправил несколько существующих правил и добавил новые.

Исправил:

- обнаружение фишинговых писем с `.exe`-вложениями
- обнаружение запуска подозрительных процессов

Также создал правила для:

1. изменений в реестре, связанных с автозагрузкой
2. разведки через `net`, `ipconfig`, `whoami` и другие системные утилиты
3. бокового перемещения через RDP и SMB
4. передачи большого объёма данных на внешний IP
5. очистки журналов через `wevtutil.exe`
