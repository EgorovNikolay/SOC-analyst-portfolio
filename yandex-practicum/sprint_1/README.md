# Спринт 1. Детектирование Brute Force, Kerberoasting, Port Scanning и DNS Tunneling

## О проекте

В этом спринте работал с тестовым стендом, на котором моделировал несколько типов атак и затем разбирал оставшиеся после них события.

Основная задача была в том, чтобы посмотреть на атаку со стороны SOC-аналитика: найти следы активности в логах и сетевом трафике, понять, какие события можно использовать для детектирования, и настроить базовые механизмы обнаружения.

## Что делал

- проводил Brute Force по RDP с помощью Hydra
- выполнял Kerberoasting с использованием Impacket
- сканировал хосты и порты через Nmap
- разбирал DNS Tunneling
- анализировал Windows Security Log
- смотрел сетевой трафик в Wireshark
- настраивал Snort для обнаружения сканирования
- настраивал правила iptables
- проверял события в syslog

## Стенд и инструменты

- **Kali Linux**: Hydra, Impacket, Nmap
- **Windows Server 2019**: Active Directory, DNS, Security Log
- **Ubuntu 22.04**: Snort, iptables
- **Wireshark**

## Что удалось обнаружить

### RDP Brute Force

В Windows Security Log были видны множественные неуспешные попытки входа с `Event ID 4625`, после которых появился успешный вход `Event ID 4624`.

Это позволило связать серию неудачных аутентификаций с последующим успешным входом.

### Kerberoasting

При запросе сервисного билета Kerberos анализировал событие `Event ID 4769`.

По этим событиям можно было увидеть обращения к сервисным учётным записям и использовать их как один из признаков Kerberoasting.

### Port Scanning

Сканирование портов фиксировалось в сетевых событиях.

Для обнаружения использовал:

- Snort
- iptables
- syslog

В логах появлялись события, связанные с `PORTSCAN`, а Snort генерировал соответствующие алерты.

### DNS Tunneling

В Wireshark разбирал DNS-трафик и искал запросы, которые отличались от обычных DNS-обращений.

Основное внимание обращал на необычную структуру и длину DNS-запросов, которые могли использоваться для передачи данных через DNS.

## Результат

В ходе работы разобрал, какие следы оставляют разные типы атак в Windows, Linux и сетевых логах.

Отдельно отработал связь между действиями атакующего и событиями, которые может увидеть SOC-аналитик:

- `4625` и `4624` при Brute Force
- `4769` при работе с Kerberos
- сетевые события при сканировании портов
- аномалии в DNS-трафике
- алерты Snort и события iptables
